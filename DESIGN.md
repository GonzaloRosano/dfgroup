# Design System — Dark Feather Group

## World

Multi-page noir studio: FinChat-like composure (floating pill nav, centered hero, black field) fused with Dark Feather atmosphere (soft WebGL nebula, ember core).

## Structure

| Route | Purpose |
|---|---|
| `/` | Landing — thesis + product gate |
| `/hosting` | DF Hosting |
| `/series` | DF Series |
| `/atelier` | DF Atelier |
| `/voices` | DF Voices |
| `/grupo` | About the collective |
| `/contacto` | Contact |

## Palette

| Token | Hex | Role |
|---|---|---|
| Void | `#0D0D0D` | Page ground |
| Ink | `#050506` | Deep panel |
| Panel | `#12141A` | Surfaces |
| Fog | `#9AA3B2` | Body secondary |
| Mute | `#6B7280` | Meta |
| Bone | `#F4F4F5` | Primary text / solid CTA |
| Ember | `#9A3B3B` | Quiet accent |

## Typography

- Display: Big Shoulders Display
- Body: Figtree

## Signature

Floating pill navigation; white pill CTAs on black; Three.js nebula behind home hero; product pages as dedicated routes (not a single-page scroll).

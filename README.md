# Dark Feather Group

Sitio web público de **Dark Feather Group** (también Dark Feather / DF Group), un colectivo creativo / estudio digital que cubre diseño, desarrollo, arte y producción.

El objetivo del sitio es que un visitante entienda quiénes son, perciba la calidad del trabajo y sepa cómo iniciar una conversación o colaboración.

## Rutas

- `/` — inicio
- `/hosting`
- `/series`
- `/atelier`
- `/voices`
- `/grupo`
- `/contacto`

## Stack

- [Astro](https://astro.build)
- React (islands puntuales para Three.js / WebGL)
- pnpm como package manager
